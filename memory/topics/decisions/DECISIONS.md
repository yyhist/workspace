# 决策固化索引

> **作用**: 跨会话可追溯的关键决策记录
> **触发条件**: 工具成功调用后的结构化输出，或一航/溯明确标记的决策
> **更新纪律**: 确认工具成功后才追加，不覆盖历史

---

## 决策记录格式

```
- **ID**: D{序号}
- **时间**: YYYY-MM-DD HH:MM CST
- **摘要**: ≤140字符
- **上下文**: 什么场景下做的决策
- **采纳方案**: 选择了什么
- **否决方案**: 放弃了什么
- **验证状态**: provisional / confirmed / overturned
- **相关项目**: 指向项目档案
```
