## 四、关键 Issues / 近期社区报告 (10条最新)

### 🔥 高危 — 2026.4.29 版本性能问题

Issue #75437 — Gateway blocks event loop 30s+ per message
   - 作者: alvaro-raise
   - 标签: 无
   - 影响: 所有 2026.4.15 ~ 2026.4.29 版本
   - 症状: Gateway 每次启动和每条消息都会重新 staging bundled runtime deps,
           manifest 从未持久化
   - 用户体验: Telegram 消息响应延迟 30秒 ~ 3分钟
   - 已确认: Telegram + MS Teams aspire-help bot 均受影响
   - 最低复现: 全新 --dev profile, 无 host state, 无插件
   - URL: https://github.com/openclaw/openclaw/issues/75437

Issue #75429 / #75430 — TUI startup hangs at 100% CPU
   - 作者: suifatt7799-oss
   - 症状: openclaw tui 启动时 CPU 100%, 无法 Ctrl+C, 只能 kill -9
   - 诊断: bundled plugin loader 在 tight loop 中反复重载 49 个 provider 插件
   - 影响版本: 2026.4.29 (2026.4.24 正常)
   - URL: https://github.com/openclaw/openclaw/issues/75430

### 🐛 Bug — 渠道/多代理

Issue #75434 — Feishu multi-agent accounts broken
   - 作者: huihongze
   - 标签: bug, regression
   - 症状: 多 agent Feishu 路由正确但 session 文件解析回默认 'main' agent
   - 非主 agent 无法处理消息
   - 期望: 每个非主 agent 应正确解析自己的 session 目录、workspace、identity、memory
   - URL: https://github.com/openclaw/openclaw/issues/75434

Issue #75433 — Embedded channel reply runs crash on SecretRef-backed credentials

Issue #75428 — Answer question too slow after update to 4.29

   - URL: https://github.com/openclaw/openclaw/issues/75428

Issue #75426 — Signal inbound/SSE listener appears wedged
